# 抖音知识型视频工作流重建

这是一个面向抖音单账号的知识型视频内容工作流记录仓库，重点记录从热点和资料到口播稿定稿的可复盘流程。

## 项目范围

当前账号方向：认知提升、商业模式、职场跃迁、逆袭成长。

当前内容阶段：选题、事实与案例、外部AI复核、观众价值、口播稿初稿、开头与标题、深度定稿和发布后复盘。

当前硬约束：

- 平台：抖音；
- 单账号；
- 口播稿正文不超过1000字；
- 事实、案例、解释、观点和建议分层；
- 公开热点是流量入口，公开可靠资料是价值增强层；
- 所有定稿必须通过高热度与观众价值双重审核；
- 参考账号只迁移结构机制，不逐句仿写或搬运案例。

## 核心流程

```text
热点入口
→ 资料匹配
→ 选题确认
→ 观众价值简报
→ 事实与案例
→ 外部AI复核
→ 口播稿初稿
→ 10个开头与10个标题
→ 用户确认组合
→ 全文定稿重构
→ 高热度与观众价值双审
→ 发布后数据复盘
```

开头和标题采用后置流程：先把内容初稿讲成立，再从成形正文中提炼和测试入口。

## 目录

- `技能库/`：项目技能与脚本入口；
- `技能记录/`：技能验收和使用记录；
- `口播稿系统/`：总流程、模板、研究报告和审核清单；
- `选题项目/`：选题卡、事实包、外部AI复核、版本化口播稿和审计记录；
- `第一轮分析资料/`：第一轮公开素材分析索引；
- `资料库/资料索引/`：资料入口说明和索引方法。

## 公开范围与排除范围

本仓库只公开流程和可复盘记录，不公开原始素材资产。

排除内容包括：第三方抖音视频、原始音频、原始PDF/Word文件、付费资料原文、Whisper或其他模型缓存、Python运行时缓存、可执行文件、动态库、临时解包目录、下载工具和凭证。

如果需要复现，使用者应自行准备公开可访问的资料，并按技能说明重新采集和验证；仓库中的事实包只代表对应测试时间点的研究记录，不替代发布前时效复核。
