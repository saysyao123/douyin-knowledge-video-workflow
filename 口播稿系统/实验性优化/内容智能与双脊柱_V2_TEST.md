# 内容智能与双脊柱 V2 TEST

> 状态：实验规则，不替换现有主流程与 `douyin-knowledge-script-engine`。
> 目的：验证在现有“事实可靠＋观众价值＋Hook后置＋高热度门禁”基础上，增加内容选择能力，是否能显著提升口播稿的信息密度、认知反转、留存连续性与可复用价值。

## 1. 本轮只增加四个能力

1. **信息价值分级**：研究资料不是等权进入正文，先分 S/A/B/C/D 五级。
2. **核心发现优先**：正文不是从“背景”开始，而是围绕最改变观众判断的事实组织。
3. **双脊柱留存**：每个语义块同时记录“新增信息”和“下一段驱动力”。
4. **可复用价值门禁**：知识型稿件优先交付一个可迁移的判断框架、观察指标、避坑方法或行动顺序；如果本题不适合方法化，必须明确说明，不能硬凑清单。

## 2. 信息价值分级

### S级：核心发现

- 没有它，这条视频的核心观点就不成立；
- 优先具备“强证据＋认知变化”双重价值；
- 2分钟稿原则上只保留 1 个 S 级发现。

### A级：强支撑

- 直接证明或限制 S 级发现；
- 允许 1—2 个进入正文；
- 如果 A 级材料只是重复 S 级，不进入正文。

### B级：解释材料

- 有助于理解，但删掉不影响主要判断；
- 仅在观众理解存在断点时使用。

### C级：背景材料

- 研究阶段有用，口播时间价值低；
- 默认不进入正文。

### D级：禁用/噪音

- 未核验、争议未解决、与核心问题弱相关、容易造成误导，或只提供热闹不提供判断；
- 不进入正文。

## 3. 核心发现卡

进入结构设计前必须回答：

- 观众最可能不知道、但最改变判断的事实是什么？
- 最强证据是什么？
- 这个证据同时证明了什么、又限制了什么？
- 表面现象是什么？真正值得关注的信号是什么？
- 如果整条视频只能保留一句判断，保留什么？
- 看完以后，观众能把什么判断方法迁移到下一件类似事情上？

如果无法形成清晰的“核心发现”，退回内容挖掘，不得用更多资料堆出正文。

## 4. 观点树

一条视频仍然只保留一个核心观点，但允许 2—3 个支撑判断：

```text
核心观点
├─ 支撑判断 A
├─ 支撑判断 B
└─ 支撑判断 C
```

每个支撑判断必须至少连接一个已核验事实、案例或明确推理。不得用多个平行观点代替核心观点。

## 5. 双脊柱留存

每个语义块同时填写：

- **信息脊柱**：本段新增了什么？
- **好奇脊柱**：听完本段，观众自然还会追问什么？

理想关系不是 `A讲完 → B讲完 → C讲完`，而是：

```text
回答 A
↓ 同时打开问题 B
回答 B
↓ 同时打开问题 C
回答 C
↓ 得出可复用判断
```

硬检查：

- 连续两个语义块不能没有信息推进；
- 连续两个语义块不能都没有下一段驱动力；
- “你知道为什么吗”“更重要的还在后面”等空悬念不算好奇脊柱；
- 下一段驱动力必须来自真实逻辑缺口，而不是文案技巧。

## 6. 可复用价值门禁

定稿前优先回答：

> 观众以后遇到同类问题，可以复用什么？

允许形态：

- 三问判断法；
- 观察指标；
- 决策顺序；
- 避坑清单；
- 对比框架；
- 可操作步骤。

禁止为了“有干货”强行凑三点、四点。若题目本身主要价值是事实更新或故事体验，可明确标记为 `FACT_UPDATE` / `NARRATIVE_VALUE`，不强制方法化。

## 7. Hook仍然后置

本实验不改变现有 Hook 后置规则。

顺序：

```text
事实包
→ 内容价值分级
→ 核心发现
→ 观点树
→ 双脊柱
→ 内部正文结构
→ 再生成多机制 Hook
→ 选择能被正文最快兑现的入口
→ 定稿重构
```

Hook候选至少覆盖：强证据、反直觉判断、现实冲突、结果前置四种机制；日常试跑不要求固定生成10个。

## 8. 本实验验收

与原 V4 对比，不以内部总分高低作为唯一结论，重点判断：

1. 是否更快进入最强事实；
2. 是否减少背景、列表和重复解释；
3. 是否形成连续问题链，而不是平行知识点；
4. 核心观点是否更容易复述；
5. 看完是否得到可迁移的判断工具；
6. 是否仍完整保留事实边界和限制条件；
7. 是否更适合自然口播。

只有测试结果明显优于原流程，才考虑将本规则并入主 Skill。
