# 口播稿交付前总检查

## 选题

- [ ] 选题来自国内7/14天、国际热点或资料库常青内容，并已标记类型
- [ ] 热点有公开来源、采集时间和热度证据
- [ ] 与账号方向和目标观众有真实联系
- [ ] 没有静默重复历史话题
- [ ] 候选选题已由用户确认

## 事实与案例

- [ ] 所有核心事实有一手来源或两个独立可信来源
- [ ] 时间、数字、人物和案例关系准确
- [ ] 来源冲突已记录并处理
- [ ] 事实、解释、观点、建议已经区分
- [ ] 外部AI复核结果已归档
- [ ] 复核不通过项未写入正文

## 观众价值简报

- [ ] 已完成《观众价值简报》并归档
- [ ] 目标观众已具体到现实处境，不是“所有人”
- [ ] 已明确回答为什么现在看
- [ ] 已明确回答看完有什么用
- [ ] 价值是判断、方法、指标、避坑或行动顺序，而不是泛泛了解新闻
- [ ] 已明确表面现象、真正问题和观众现实落点

## 开头与标题

- [ ] 口播稿初稿已先完成并通过内部初稿审查
- [ ] 已生成10个开头和10个标题
- [ ] 10个开头至少覆盖4种不同机制，不是同一句话的同义改写
- [ ] 每个开头都能在3秒内理解
- [ ] 开头承诺能被正文兑现
- [ ] 标题没有把推测写成事实
- [ ] 已给出评分、推荐组合和备选组合
- [ ] 用户已确认采用组合

## 正文

- [ ] 只有一个核心问题和一个核心观点
- [ ] 开头、冲突、观点、案例、解释、结论关系清楚
- [ ] 1—2个案例均可追溯
- [ ] 每个段落都提供新信息或推动理解
- [ ] 没有空泛铺垫和重复解释
- [ ] 句子适合口播，长句已拆分
- [ ] 字数不超过1000字
- [ ] 表达直接但不侮辱、不造谣、不夸大
- [ ] 财富、投资、商业机会和职场建议没有保证性承诺
- [ ] 观众价值专项评分不低于85分，且没有硬性门禁失败

## 高热度专项门禁

- [ ] 第一口在约3秒内说清事件/人物/现象
- [ ] 前1—3句同时具备事件、目标观众痛点或冲突、可核验具体信号
- [ ] 起草目标第一句约15—25个汉字，前三句合计约55字以内；已按实际录音复测
- [ ] 具体信号已回指事实与案例清单，没有使用未核实排名、数字或日期
- [ ] 已明确表面现象与真正值得关注的底层信号
- [ ] 前5—8秒已经兑现观看承诺，观众知道继续看能得到什么
- [ ] 每5—10秒有新事实、新对比、新问题、新转折或新结论
- [ ] 连续两个语义块之间不存在同义重复或空泛解释
- [ ] 至少有3个留存节点：开头冲突、证据/案例反转、结论或生活落点
- [ ] 每个三点以上的清单都写明了对观众的具体意义
- [ ] 至少1个真实案例和1个可核验具体证据点进入正文
- [ ] 结尾回扣开头，并有一句可复述的判断句
- [ ] 互动为轻量场景问题，可选地引导评论/收藏/关注，无收益或购买承诺
- [ ] 高热度专项评分不低于85分，且前3秒、具体信号、段落留存均达到最低分
- [ ] 没有为制造热度而出现夸大、投资诱导、替代人工承诺或直接仿写

## Humanization实验门禁（仅用于实验标记）

- [ ] 已先完成 STRUCTURED 版，且事实、核心观点、案例和观众价值已通过检查
- [ ] HUMANIZED 版与 STRUCTURED 版使用同一事实底稿，没有新增未经核验的事实、案例或确定性判断
- [ ] 内部框架已按需要隐藏，但教程步骤、事实限制和核心判断没有被隐藏到无法理解
- [ ] 至少有一个具体事件、操作场景、前后对比或生活翻译承载抽象观点
- [ ] 每5—10秒仍有有效推进，允许的短缓冲均有明确功能，不靠“其实/你看/说白了”堆出口语感
- [ ] 没有连续三段同句式、每句金句化、强行第一人称、伪造经历或固定复用某个类比
- [ ] Humanization 后已重新执行事实、观众价值和高热度门禁；没有信息损失、好奇链断裂、水句增加或时长失控
- [ ] A/B 对照报告记录了具体改动、收益和副作用，而不是只给总分

## 版本与归档

- [ ] 内部自审记录完整
- [ ] 总分达到85分且没有硬性否决项
- [ ] 历史版本没有被覆盖
- [ ] 文件位于唯一选题文件夹
- [ ] 若为实验回归，已归档 STRUCTURED/HUMANIZED 两版和具体对照报告
- [ ] 公开仓库没有隐私、凭证、付费全文或未经授权原始资料
