# 观众价值与有效吸引力门禁 V1.0

## 1. 目的

本门禁解决一个比“开头够不够炸”更重要的问题：这条口播稿为什么值得目标观众花两分钟看完，看完以后能用在哪里。

它与《口播稿高热度输出前审核标准》并列使用：高热度门禁检查热点入口、冲突、具体信号和段落留存；本门禁检查观众对象、观看理由、实际用途、承诺兑现和价值闭环。两项都通过，才允许标记为“可交用户审核的定稿”。

## 2. 交付前硬门禁

### V1：观众必须具体

- [ ] 目标观众不是“所有人”，而是一个具体处境中的人；
- [ ] 已写明他正在面对的工作、商业、职业、家庭或判断问题；
- [ ] 至少有一句话能让目标观众产生“这和我有关”的身份或场景关联；
- [ ] 没有使用泛化焦虑替代真实需求。

### V2：必须回答“为什么现在看”

- [ ] 热点的时间节点、最新进展、持续发酵或现实影响已经说明；
- [ ] 如果是常青内容，已说明它与当前观众处境的连接，没有伪装成即时热点；
- [ ] 不能只因为新闻“刚发生”就默认观众有观看理由；
- [ ] 没有把过期或重复话题重新包装成新热点。

### V3：必须回答“看完有什么用”

- [ ] 一句话写清观众看完能获得的判断、方法、观察指标、避坑提醒或行动顺序；
- [ ] 价值不是“了解一个新闻”这种不可使用的结果；
- [ ] 价值与目标观众的现实决策有关；
- [ ] 正文至少一处把宏大事件翻译成观众自己的工作、商业、职业或生活场景。

### V4：观看承诺必须兑现

- [ ] 开头承诺明确而有限，没有承诺全文无法完成的事情；
- [ ] 正文在前段开始兑现，而不是先铺大量背景；
- [ ] 结尾确实回答了开头问题；
- [ ] 没有用热词吸引观众、正文却转成无关鸡汤或销售内容。

### V5：价值必须有证据支撑

- [ ] 至少有1个可追溯的真实案例或具体场景；
- [ ] 至少有1个可核验的事实、数字、时间、机构动作或前后对比；
- [ ] 公司自述、媒体报道、作者分析和推测已经区分；
- [ ] 任何数字、日期、排名和结论都能回指事实清单。

### V6：每一段都要让观众更接近答案

- [ ] 全文只保留一个主要问题和一个核心观点；
- [ ] 每个语义块都能写出“本段新增了什么”；
- [ ] 每个语义块都能写出“观众为什么要继续听下一段”；
- [ ] 连续两个语义块没有同义重复或空泛转场；
- [ ] 清单或概念后面已经补充“对观众意味着什么”。

### V7：结尾必须形成可复述价值

- [ ] 结尾回扣标题或开头提出的问题；
- [ ] 有一句不依赖上下文也能复述的判断句；
- [ ] 互动问题要求观众代入具体场景，而不是单纯索取点赞；
- [ ] 没有用收益保证、恐惧、购买、课程或“逆袭承诺”换互动。

## 3. 100分评分表

评分用于返工和版本比较，不代表播放量保证。

| 维度 | 分值 | 通过标准 |
|---|---:|---|
| 目标观众具体度 | 20 | 能明确到具体处境和判断问题 |
| 为什么现在看 | 15 | 有时间节点、持续进展或现实影响 |
| 看完有什么用 | 20 | 能带走判断、方法、指标、避坑或行动顺序 |
| 证据与案例 | 15 | 有可追溯事实和真实场景，口径清楚 |
| 观看承诺兑现 | 10 | 开头承诺有限、正文兑现、结尾回答 |
| 段落推进 | 10 | 每段都有新信息或理解推进 |
| 现实落点 | 5 | 能翻译到工作/商业/职业/生活场景 |
| 结尾互动 | 5 | 有记忆句和具体场景问题 |
| **合计** | **100** |  |

通过条件：总分不低于85分，且“目标观众具体度”不低于16分、“看完有什么用”不低于16分、“证据与案例”不低于12分；V1—V7不能有硬失败。

## 5. 返工规则

- 只有热点没有观众处境：退回选题匹配；
- 有观众处境但没有事实和案例：退回事实包；
- 有事实但说不清看完有什么用：退回角度与观点；
- 有观看承诺但正文兑现不了：重写开头或重构正文，不能保留原承诺；
- 有信息但每段不推进：删除背景和重复解释，补充对比、案例、机制或现实落点；
- 结尾只有“你怎么看”：改成具体场景问题；
- 只是让稿件更夸张但没有增加价值：判定返工无效。

## 6. 发布后回填

发布后把以下数据回填到同一选题文件夹：前2—3秒停留/跳出、前5秒留存、平均观看时长、完播、重播、收藏、分享、评论质量、关注转化和观众画像。

数据复盘时优先判断：观众是否因为入口不清楚而离开，是否听到承诺但没有及时得到价值，哪个段落开始掉人，是否产生收藏/分享，以及评论是否连接到观众自己的场景。前10条先建立账号基线，不预设外部账号或其他平台的绝对阈值。
