# 审核节点与角色

## Codex负责

- 多源发现和整理热点线索；
- 资料提取、去重、分类和索引；
- 形成3—5个候选选题和评分；
- 整理事实、案例、来源和风险；
- 根据外部复核结果生成10个开头和10个标题；
- 完成内容挖掘、结构设计、留存、口语化和内部自审；
- 保存版本、过程记录和复盘数据。

## 用户必须参与

1. 从候选中确认选题；
2. 将事实和案例清单交给外部AI复核；
3. 反馈复核结果和争议项；
4. 确认推荐的开头和标题组合；
5. 审核通过自审的最终口播稿；
6. 发布后提供数据截图。

## 暂停条件

- 选题未确认；
- 外部复核未返回；
- 核心事实或案例存在未解决冲突；
- 用户审核意见尚未明确；
- 资料只能支持弱观点，却要求写成确定性结论。
