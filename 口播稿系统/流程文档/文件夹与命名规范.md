# 文件夹与命名规范

## 项目级目录

```text
D:\整体视频流程重建\
├─ 口播稿系统\
│  ├─ 流程文档\
│  ├─ 模板\
│  ├─ 审核清单\
│  └─ 参考样本\
├─ 资料库\
│  ├─ 原始资料\
│  └─ 资料索引\
└─ 选题项目\
   └─ 选题编号_中文短标题\
```

## 独立选题文件夹

例如：

`D:\整体视频流程重建\选题项目\20260818-001_豆包收费与普通人机会`

建议结构：

```text
20260818-001_中文短标题\
├─ 选题与核验\
│  ├─ 01_选题卡.md
│  ├─ 02_事实与案例清单.md
│  ├─ 03_外部AI复核结果.md
│  └─ 04_开头标题方案.md
├─ 口播稿\
│  ├─ V01_内部草稿.md
│  ├─ V02_自审定稿.md
│  └─ V03_用户审核定稿.md
├─ 视频制作\
├─ 交付\
└─ 发布复盘\
   └─ 数据复盘.md
```

## 命名规则

- 文件夹使用 `YYYYMMDD-三位序号_中文短标题`；
- 文件使用中文功能名＋版本号；
- 历史版本不覆盖；
- `定稿`只能指通过内部自审并经用户确认的版本；
- 资料原件保留原文件名，索引中另加资料ID；
- GitHub公开文件不放入隐私、凭证、付费全文或未经授权的原始素材。
