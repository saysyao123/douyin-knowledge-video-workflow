## 适用范围

本技能只负责“内容理解到口播定稿”这一段，不负责视频画面、配音、剪辑和发布。默认项目根目录是 `D:\整体视频流程重建`，项目内的资料、记录和选题文件夹使用中文名。

当前账号方向：认知提升、商业模式、职场跃迁、逆袭成长；主要服务抖音；字数以 1000 字以内为硬上限，实际口播时长以后续用户录音为准。

参考基线：

- `鼎极财富笔记`：选题方向、内容逻辑和价值感；
- `张琦老师—商业咨询`：口播表达、直接、一针见血和观点推进；
- `复利研习社`：AI视频呈现形式，不作为文字逐句模仿对象。

学习的是结构、节奏和表达机制，不复制原句、段落或案例，不以规避原创检测为目标。

## 总流程与门禁

### 0. 建立写作基线

使用项目内已下载的参考账号视频，完成转写和结构分析，形成风格基线。新增参考视频只在对标账号出现明显新结构，或本账号某项指标持续不足时补充。

### 1. 两种输入入口：热点优先、资料增强

- 热点入口是默认起点：先扫描抖音、微博、头条等公开流量入口，再做跨平台归并和持续性判断；
- 资料入口是价值增强层：从 `D:\整体视频流程重建\资料库\原始资料` 接收零散文件，提取认知框架、商业机制、职场经验、案例和表达素材，再与已筛选热点匹配。

资料可以是文章、新闻、研究、Word、PDF、网页、图片、截图、音频、视频、Markdown 或纯文本。原始文件不改动，分析结果另存索引。

热点和资料必须有真实联系；不能强行借热点包装资料。平台榜单是流量信号，不是事实来源；评论和二次解读是受众语言线索，不是事实来源。热点有价值但事实不稳定时，只能做预热型选题，不得使用未确认事实作为核心结论。

### 2. 选题候选：先流量，再价值，最后证据

每轮先从抖音、微博、头条等入口采集线索，合并同一热点实体，再用公开权威来源做事实边界检查，最后从资料库匹配内容价值。每轮交付 3—5 个候选选题，并记录平台信号、跨平台共振、持续性、资料依据、核心价值、独特角度、事实风险和评分。用户选定一个后，才能进入事实与案例阶段。

日更目标下的扩展顺序是：国内7天热点 → 国内14天持续热点 → 国际热点 → 资料库常青选题。重复话题必须单独标记并交用户审核；没有合适热点时，不强行制造关联。

初评采用：流量入口信号30分、跨平台共振15分、持续性15分、目标受众关联15分、资料匹配15分、事实可核验性10分。热度高不能覆盖事实、版权、平台和强行关联风险。

### 3. 事实与案例包

选题确定后先按第4节创建观众价值简报，再建立事实与案例清单。核心事实优先使用一手来源，或至少两个独立可信来源印证；来源冲突必须保留说明。外部AI复核结果未返回前，暂停 Hook、标题和正文制作。

事实、解释、观点、建议必须分开。没有可靠真实案例时不得编造，只能明确标为假设场景，或删除案例。

### 4. 观众价值合同

选题确认后先完成观众价值简报，再进入事实与案例包。事实复核要围绕这份简报验证：谁会看、他当前处境是什么、为什么现在看、表面现象是什么、真正问题是什么、看完能获得什么判断/方法/避坑/行动顺序，以及结尾要让观众代入什么场景。

硬停止条件：无法用一句话写清“为什么现在看”和“看完有什么用”，不得进入口播稿制作；目标观众只写“所有人”、价值只写“了解一下新闻”、或热点与观众处境之间没有真实连接，都必须退回选题角度阶段。

### 5. 口播稿初稿

外部AI复核通过后，先完成一版内部口播稿初稿。初稿先解决事实、观点、案例、机制和观众价值是否成立，不先追求最终标题和前三秒竞争。

初稿需要完成：

1. 从已核验材料中找信息差、认知冲突、实用价值、证据和身份关联；
2. 一条视频只解决一个主要问题，明确核心观点和观众最后记住的一句话；
3. 按观众理解顺序重排：临时入口、问题、信息增量、转折、案例、解释、结论和行动；
4. 为每个语义块记录本段新增了什么、观众为什么要继续；
5. 完成内部初稿审查：事实可回指、案例服务观点、观众用途落地、没有明显空转。

临时入口只用于承载初稿，不作为最终交付开头。初稿不交用户，也不标记为定稿。

### 6. Hook 与标题后置

初稿内容基本成立后，再从已经写成的正文中提炼入口和标题。生成10个开头和10个标题，分别评分，给出推荐组合，并记录每个开头在正文中的兑现位置。10个开头必须是至少4种不同机制的测试组，不得只是同一句话的10次同义改写。

用户确认开头和标题组合后，才进入全文定稿重构。评分是比较工具，不是上榜或播放量保证。

### 7. 定稿深度制作

交给用户的必须是通过内部自审的定稿，不交未经处理的原始初稿。内部按以下模块完成：

1. 按用户确认的开头和标题重构全文；只保持用户确认开头的核心意思，允许调整句式、顺序和措辞；
2. 口语化：短句、自然停顿、可一口气说完，删除文章味和AI套话；
3. 风险审核：事实、案例、人物、企业、商业机会、财富和职场建议分别检查；
4. 高热度增强：单独检查前3秒“事件＋痛点/冲突＋可核验具体信号”，并建立段落级留存脊柱、信息差反转和结尾记忆点；
5. 观众价值复核：检查为什么现在看、看完有什么用、每个语义块的新增价值，以及开头承诺是否兑现；
6. 脚本评分与返工：基础口播、高热度专项和观众价值专项都达到门槛，且没有硬性否决项，才能交付。

高热度不是把标题写得更夸张。没有可核验数字时，可以使用实名机构动作、真实场景、明确规模或前后对比作为具体冲击；不得编造数字或用未确认热榜排名代替证据。起草时第一句目标约15—25个汉字，前三句合计约55字以内，最终以用户录音实测为准。每5—10秒必须有新事实、新对比、新问题、新转折或新结论；连续两个语义块没有推进时必须返工。

默认正文骨架是：开头钩子 → 痛点或冲突 → 为什么重要 → 核心观点 → 1—2 个核验案例 → 对观众的启发或行动建议 → 一句话收束与适度互动引导。

### 8. 用户审核与复盘

定稿交用户审核后，按版本号保存修改，不覆盖旧版本。发布后用户提供抖音后台截图，提取并保存留存、互动、涨粉和受众数据，与对应口播稿关联，反向更新基线。

## 硬性停止条件

出现以下任一情况，不能用高分或高热度理由覆盖：事实未核验、案例疑似虚构、来源冲突未说明、观点超出证据、个人观点被写成事实、明显逐句仿写、严重标题党、法律或平台风险、外部AI复核未完成、观众价值简报缺失、无法回答为什么现在看或看完有什么用、前3秒没有事件＋观众冲突＋可核验具体信号、正文没有段落级留存记录、连续两个语义块没有信息推进、开头承诺未兑现、结尾没有回扣问题和可记忆判断句、为制造热度强行加入未核实数字/日期/排名或确定性承诺。
