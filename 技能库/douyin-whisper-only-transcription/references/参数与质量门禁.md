# Whisper唯一转写参数与质量门禁

## 固定环境

| 项目 | 固定值 |
|---|---|
| Python | `C:\Python314\python.exe` |
| Whisper | `openai-whisper 20250625` |
| Torch | `2.10.0+cpu` |
| 主模型 | `large-v3-turbo` |
| 主模型文件 | `C:\Users\adminmailbox\.cache\whisper\large-v3-turbo.pt` |
| 辅助模型 | `small`，只处理争议词 |
| 音频事实来源 | 输入媒体原始音轨 |

## 固定推理参数

```json
{
  "language": "zh",
  "task": "transcribe",
  "fp16": false,
  "word_timestamps": true,
  "condition_on_previous_text": true,
  "temperature": 0.0,
  "beam_size": 5,
  "best_of": 5
}
```

争议词复核仍然使用同一个OpenAI Whisper环境和 `small.pt`。它只提供候选读法和时间点，最终主文本不自动被辅助结果覆盖。

## 任务文件格式

```json
[
  {
    "id": "账号_样本编号_标题",
    "audio": "D:\\整体视频流程重建\\素材库\\对标账号视频\\样本.mp4",
    "pass": "large-v3-turbo_primary"
  }
]
```

输入可以是视频或音频。建议使用绝对路径；相对路径按任务文件所在目录解析。ID必须唯一。

## 输出文件格式

输出是JSON数组，每条记录至少包含：`id`、`audio`、`model`、`device`、`python`、`whisper_version`、`torch_version`、`parameters`、`language`、`text`、`segments`和`duration_seconds`。`segments`保留 `start`、`end`、`text`，用于开头、停顿、转折和结构定位。

脚本会在每条任务完成后原子替换正式JSON；`.part`文件只代表未完成的检查点，不得作为交付物。中断后重新运行同一任务文件和输出文件即可跳过已完成ID。

## 完成门禁

- 当前解释器路径和版本符合固定环境；
- 模型文件存在且大小没有明显异常；
- FFmpeg可用；
- 每个任务输入文件存在；
- 任务ID和已有输出ID没有重复；
- 每个完成记录都包含非空文本和分段时间戳；
- 语言标记为`zh`；
- 正式交付前不存在未完成的`.part`文件；
- 品牌、人名、数字和疑似口误已标记待复核，不被语言润色掩盖。

## 禁止替代

不得用平台自动字幕、视频描述、旧稿、外部AI转写或`faster-whisper`替换正式主转写。它们最多只能作为人工发现问题的线索，不能写入主结果或覆盖原始音频证据。
