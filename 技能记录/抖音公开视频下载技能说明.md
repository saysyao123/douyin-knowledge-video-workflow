## 已固化的路径

1. 从公开账号主页发现候选，但最终记录具体作品页 URL 和作品 ID。
2. 使用 Codex 应用内浏览器打开公开视频页，读取当前 `video/source` 暴露的公开媒体地址。
3. 只接受 `douyinvod.com` 或抖音公开播放接口地址；不读取本机 Cookie，不绕过登录、验证码或付费限制。
4. 通过 `.part` 临时文件下载，基础媒体识别通过后再原子移动为 `.mp4`。
5. 使用 FFprobe 读取容器、时长、分辨率、音视频流和编码。
6. 使用 FFmpeg 全量解码，并生成 SHA-256。
7. 将来源、选择规则、替补关系、失败状态和校验结果写入中文记录目录。

## 使用边界

这套技能证明的是“公开页面媒体可以被稳定采集并完成文件完整性校验”，不等于获得原作者内容的再发布授权，也不自动完成事实核验、口播稿转写或视频发布。

签名媒体地址具有时效性，长期复盘以公开视频页 URL、作品 ID、采集时间和 SHA-256 为准。
