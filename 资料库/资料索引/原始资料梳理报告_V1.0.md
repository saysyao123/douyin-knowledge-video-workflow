## 3. 对口播风格的有效参考

抽样阅读结果显示，适合转化的结构不是“把文章缩短”，而是：

1. 先用一个现实问题、热点案例或冲突开场；
2. 直接提出观众想知道的问题；
3. 先定义问题，再拆解机制；
4. 用一个具体场景把抽象概念落地；
5. 提炼一句可记忆的判断；
6. 给出观众能理解的行动方向。

其中“问题分析”“现象与本质”“产品定位”“市场竞争”等资料特别适合承担解释框架；“吸睛标题”和“高点击率主图”类资料只能作为历史方法参考，不能直接等同于当前抖音分发规则。

## 4. 必须过滤的风险

- 资料中存在2021年前后的历史内容，不能直接作为当前新闻或市场事实；
- 部分文件来自知乎盐选或付费内容，不能把全文或大段原文上传到公开GitHub；
- 某些标题使用“100%”“年化收益20%”“低风险”等强承诺表达，必须删除或降级为资料原观点并重新核验；
- 部分职场和社会案例使用强烈、绝对或带侮辱性的判断，需转换为中性机制分析；
- 小说、情感和案件类文件数量较多，但不应因为有戏剧性就直接纳入当前账号核心方向。

## 5. 与热点入口的正确关系

本资料库不负责回答“今天什么最热”，负责回答“一个热点为什么值得讲、可以讲出什么深度”。

正确用法：

```text
热点入口发现话题
→ 公开来源确认事实
→ 资料库匹配解释框架
→ 形成认知提升、商业模式、职场跃迁或逆袭成长角度
```

错误用法：

```text
从旧文章找到一个观点
→ 强行寻找一个当天热点
→ 把热点当包装
```

后者容易造成“资料准确但没人关心”或“热点相关但内容空泛”，不再作为默认流程。
