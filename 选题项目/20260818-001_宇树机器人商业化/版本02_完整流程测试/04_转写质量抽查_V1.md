# 参考样本转写质量抽查 V1

## 1. 结论

5条样本均由当前已验证的 `openai-whisper large-v3-turbo` 完成，均有中文语言标记、分段时间戳和原始连续文本。转写适合做结构与节奏分析；涉及专有名词、数字和观点事实时，仍必须回听原视频，不能把ASR文字直接当作事实引用。

## 2. 已发现的疑似识别问题

| 样本 | 疑似问题 | 处理 |
|---|---|---|
| 鼎极｜高位驯化 | “高职/高成就/高位置”等连续词可能被合并为“高任职高成就高位职”；“高位驯化”个别位置可能识别漂移 | 结构分析按上下文理解，正文不引用该样本事实 |
| 鼎极｜最强掠夺法 | 结尾出现重复“订阅”，明显可能是片尾口播或音频重复导致的识别结果 | 不作为正常CTA基线，回到原视频核验 |
| 复利｜稳富 | “稳富”及书名多次出现近音识别；“扣非/投资”等词也可能受口音影响 | 不把书名、收益和金融表述作为本项目事实 |
| 张琦｜豆包收费 | Kimi、DeepSeek、Cursor、Gemini等专有名词需回听或查原文；收费政策属于时效事实 | 只借结构，不直接引用其政策判断 |
| 张琦｜AI财富趋势 | “985”“12年”等数字和专有名词存在明显ASR歧义；“两亿”等市场数字必须独立核验 | 不直接采信，任何数字单独查证 |

## 3. 使用原则

- ASR文本用于分析“说了什么、什么时候说、如何推进”；
- 视频原音用于确认有争议的字词、数字、品牌和人名；
- 公开来源用于确认事实，不能用参考视频的口播作为证据来源；
- 参考样本中的观点只用于分析表达机制，不代表本账号立场。
