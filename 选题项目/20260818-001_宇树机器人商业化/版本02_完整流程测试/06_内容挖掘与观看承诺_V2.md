# 内容挖掘与观看承诺 V2

## 1. 观众和真实问题

目标观众是关注商业变化、职业机会和技术趋势的30—55岁用户。他们能看到机器狗翻跟头、人形机器人跳舞，也能看到“上市”两个字，但很难判断：

- 这是技术展示，还是已经能稳定完成工作；
- 这是公司进入资本市场，还是商业模式已经成熟；
- 机器人离普通家庭，究竟差的是时间、价格，还是可靠性。

## 2. 信息差

大众讨论容易停留在“会不会翻跟头”和“股票会不会涨”；本轮真正有价值的信息差是：上市是资本市场事件，机器人进入日常生活却要通过产品、场景、成本、安全和服务的连续验证。

## 3. 核心问题与核心观点

- 核心问题：宇树上市之后，机器人距离普通人的日常生活还有多远？
- 核心观点：上市是资本市场的一道门，不是商业化毕业证；判断机器人何时进入日常生活，不能看动作有多炫，要看它能否在真实场景中稳定、低成本、安全、可维护地重复完成任务。
- 观众看完应记住的一句话：机器人进入家庭的时间，不由它能不能走决定，而由它能不能长期把一件具体的事做好决定。

## 4. 观看承诺

继续看完，观众会得到一个不依赖股价的判断框架：

1. 它有没有进入真实的工作场景；
2. 它能不能稳定完成可重复任务；
3. 成本、安全和责任有没有被解决；
4. 有没有售后和持续服务体系。

## 5. 证据—观点映射

| 口播段落 | 使用材料 | 事实/观点边界 |
|---|---|---|
| 热点入口 | 用户确认的T2-01与H2-11；具体日期需发布前复核 | 热点包装，不扩大为股价判断 |
| 不是单纯展示 | 宇树官网业务定位 | 公司自述，只支持“业务覆盖” |
| 真实场景 | 央视青岛消防报道 | 可确认列装和测试，不能写成熟商用 |
| 仍有距离 | “仍处于测试阶段”与公司风险边界 | 事实加分析，不下绝对结论 |
| 四道门 | 价格、稳定性、安全责任、服务体系 | 本账号分析框架，不是官方预测 |
| 普通人落点 | 行业场景先于家庭场景的商业推断 | 明确是基于任务标准化和风险条件的分析 |

## 6. 不能写成的逻辑跳跃

- 从“上市”跳到“已经全面商业化”；
- 从“进入消防测试”跳到“已经替代消防员”；
- 从“公司展示行业方案”跳到“行业已经大规模落地”；
- 从“机器人未来有机会”跳到“普通人抓住风口就能逆袭”；
- 从“明天挂牌”跳到“股价一定上涨”。
